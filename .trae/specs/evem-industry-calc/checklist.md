# Checklist

## 项目初始化
- [ ] React + Vite + TypeScript 项目能正常启动和构建
- [ ] 依赖库（KaTeX 等）正确安装

## 数据层
- [ ] 所有 TypeScript 类型定义完整且无编译错误
- [ ] 制造材料数量计算正确（材料效率、解码器加成、流程数独立乘算）
- [ ] 基底材料和解码器不受材料效率影响
- [ ] 解码器 runBonus 正确增加产物数量
- [ ] 逆向成功率 = 材料数量 × successRatePerItem
- [ ] 逆向期望成本 = 单次成本 / 成功率
- [ ] 市场出售：立即出售 vs 挂单的税费计算正确
- [ ] 合同出售：中介费最低于 1000、定金最低于 10000 的边界正确
- [ ] 内置 3-5 个演示产品数据完整可用

## 状态管理
- [ ] 价格配置可新建、切换、重命名、删除
- [ ] 材料单价编辑后实时保存到当前配置并持久化到 localStorage
- [ ] 页面刷新后恢复上次使用的价格配置

## 生产面板
- [ ] 制造/逆向模式可正确切换
- [ ] 产品选择器支持搜索过滤
- [ ] 效率预设下拉可选，手动输入也可用
- [ ] 解码器选择后加成预览正确显示
- [ ] 材料清单按分类展示，数量计算正确
- [ ] 流程数滑块范围正确限制
- [ ] 逆向模式：材料数量滑块影响成功率显示
- [ ] "发送到出售"正确传递成本数据到出售面板

## 出售面板
- [ ] 市场/合同模式可正确切换
- [ ] 市场出售税额计算正确
- [ ] 合同出售税额计算正确
- [ ] 利润和利润率计算正确

## 数据导入导出
- [ ] 导出 JSON 包含完整数据
- [ ] 导入 JSON 有格式校验
- [ ] 重置功能恢复内置默认数据

## 格式化
- [ ] 所有金额数字使用千位分隔符
- [ ] 时间格式化为 hh:mm:ss
- [ ] LaTeX 公式正确渲染

## 响应式
- [ ] PC 端 (≥1024px) 左右双面板布局正常
- [ ] 移动端 (<768px) 上下布局正常，材料清单卡片式

## 边界处理
- [ ] 效率值范围校验生效
- [ ] 价格未设置时材料行标黄提示
- [ ] localStorage 满时有提示
- [ ] 导入无效 JSON 时有错误提示
