# EVEM 工业计算器 Spec

## Why
《星战前夜：无烬星河》（EVE Echoes Mobile）玩家在开始工业项目前，需要计算制造成本和出售利润，但游戏内缺乏直观的利润预估工具。需要一个完全离线的网页工具，帮助玩家在点击"开启项目"之前，精确计算投入产出比。

## What Changes
- 新增完整离线工业计算网页应用
- 内置制造项目（Manufacturing）和逆向工程（Reverse Engineering）两大计算模式
- 支持市场出售和合同出售两种利润估算
- 内置演示级产品数据，支持 JSON 导入导出
- 多套价格配置缓存，localStorage 持久化

## Impact
- Affected specs: 无（全新项目）
- Affected code: 全新项目，React + Vite + TypeScript 技术栈

## ADDED Requirements

### Requirement: 制造项目计算
系统应提供制造项目成本计算功能，包含材料数量计算、时间计算和现金费用计算。

#### Scenario: 标准制造计算
- **WHEN** 用户选择产品蓝图、设置材料效率(150%/97%/96%/95%或手动)、时间效率(100%/47.81%/45%或手动)、流程数
- **THEN** 系统展示所有材料的分类数量、总成本、总耗时、现金费用、单件成本

#### Scenario: 解码器加成
- **WHEN** 用户选择解码器
- **THEN** 系统将解码器成本计入总成本，将其 ME/TE/流程加成应用于计算，基底材料和解码器本身不受材料效率影响

### Requirement: 逆向工程计算
系统应提供逆向工程项目计算，包含成功率、数学期望成本。

#### Scenario: 逆向材料数量影响成功率
- **WHEN** 用户配置基底材料数量（1到蓝图定义的maxItemCount）
- **THEN** 成功率 = 材料数量 × 蓝图定义的successRatePerItem，显示期望成本 = 单次成本 / 成功率

#### Scenario: 逆向工程完整成本
- **WHEN** 配置逆向工程所有参数
- **THEN** 材料总成本包含基底材料、数据核心、解码器、ISK费用，期望成本用于利润估算

### Requirement: 出售利润计算
系统应支持市场和合同两种出售方式的税费和利润计算。

#### Scenario: 市场出售
- **WHEN** 用户选择市场模式、输入售价、选择是否立即出售、设置销售税率
- **THEN** 系统根据立即出售规则计算中介费(1%)、销售税、税后收入、总利润、利润率

#### Scenario: 合同出售
- **WHEN** 用户选择合同模式、输入售价
- **THEN** 系统计算中介费(4%, 最低1000)、定金(2.5%, 最低10000，提示成交后退还)、税后收入、利润

### Requirement: 生产与出售联动
系统应支持将生产计算结果传递至出售面板。

#### Scenario: 发送到出售
- **WHEN** 用户在生产面板点击"发送到出售"
- **THEN** 总成本、单件成本、产品数量自动带入出售面板，出售面板实时更新利润

### Requirement: 价格配置管理
系统应支持多套价格配置的创建、切换、编辑和持久化。

#### Scenario: 创建和切换价格配置
- **WHEN** 用户创建新价格配置或切换已有配置
- **THEN** 所有材料价格使用当前激活配置的单价，编辑单价实时保存到当前配置并持久化到 localStorage

### Requirement: 数据导入导出
系统应支持完整数据（内置数据、用户自定义产品、价格配置）的 JSON 导入导出。

#### Scenario: 导出数据
- **WHEN** 用户点击导出
- **THEN** 下载包含所有数据的 JSON 文件

#### Scenario: 导入数据
- **WHEN** 用户选择 JSON 文件导入
- **THEN** 预览差异后合并到当前数据，进行格式校验

### Requirement: 响应式布局
系统应在 PC（优先）和移动端均可正常使用。

#### Scenario: PC 端布局
- **WHEN** 视口宽度 ≥ 1024px
- **THEN** 生产和出售面板左右并排显示

#### Scenario: 移动端布局
- **WHEN** 视口宽度 < 768px
- **THEN** 面板切换为上下布局，材料清单改为卡片式

### Requirement: 数字与时间格式化
系统应统一格式化数字和时间显示。

#### Scenario: 数字格式化
- **WHEN** 展示任何数值金额
- **THEN** 使用千位分隔符

#### Scenario: 时间格式化
- **WHEN** 展示耗时
- **THEN** 默认格式 hh:mm:ss，长耗时展示 MM:dd:hh:mm:ss

### Requirement: 公式渲染
系统应使用 LaTeX 语法渲染所有展示的计算公式。

#### Scenario: 展示公式
- **WHEN** 界面展示计算公式
- **THEN** 使用 LaTeX 语法渲染（通过 KaTeX 或 react-latex-next）
