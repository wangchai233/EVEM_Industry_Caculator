# EVEM 工业计算器 v2 — 技能设施与公式重做 Spec

> 日期: 2026-07-08 | A 期（基石）

## Why
当前计算器缺乏技能和设施加成系统，解码器不区分制造/逆向，公式不完整。需要引入完整的游戏加成体系，使计算更精确，并支持产品标签匹配和折扣系统。

## What Changes
- **BREAKING**: 新增技能和设施全局加成面板，所有公式重构
- **BREAKING**: 解码器完全重做（8 个新解码器，制造/逆向分家，中文化显示）
- **BREAKING**: 材料效率公式从"用户直接选值"改为"基础1.5 + 技能 + 设施 + 解码器"
- 新增产品标签系统（树形继承）
- 新增三层折扣系统
- 新增流程数自定义（不受游戏上限限制）+ 逆向并行流程数 + 槽位计算
- 新增内置测试数据（秃鹫级截击型系列）
- 新增简明的用户教程文字

## Impact
- Affected specs: 所有与引擎、数据、UI 面板相关的 spec
- Affected code: `src/engine/`, `src/types/`, `src/data/`, `src/state/`, `src/components/ProductionPanel/`, `src/components/SellingPanel/`, `src/App.tsx`

## ADDED Requirements

### Requirement: 技能系统
系统应提供内置的技能数据，玩家可调整每个技能的三阶段等级（基础/进阶/专家），加成通过产品标签匹配生效。

#### Scenario: 技能等级约束
- **WHEN** 用户调整某技能的等级
- **THEN** 系统强制：进阶 > 0 要求基础 ≥ 4；专家 > 0 要求进阶 ≥ 5

#### Scenario: 批量设置
- **WHEN** 用户选择预设等级（000/540/550/553/554/555）
- **THEN** 所有技能按预设值设置，受等级约束限制

#### Scenario: 技能加成匹配
- **WHEN** 计算某产品的加成
- **THEN** 只匹配产品标签与技能 matchTags 有交集的技能

### Requirement: 设施系统
系统应提供内置设施数据和自定义设施加成。

#### Scenario: 设施加成匹配
- **WHEN** 选择内置设施
- **THEN** 设施加成通过标签匹配生效

#### Scenario: 自定义设施加成
- **WHEN** 用户设置自定义设施加成
- **THEN** 该加成对所有产品生效，不经过标签过滤

### Requirement: 新公式体系
所有加成遵循分层管线：技能 → 设施 → 解码器。

#### Scenario: 材料效率
- **WHEN** 计算材料效率
- **THEN** 最终值 = 1.5 + 技能加成 + 设施加成 + 解码器材料效率加成

#### Scenario: 时间消耗
- **WHEN** 计算时间消耗
- **THEN** 时间 = 基础时间 × (1 + 技能) × (1 + 设施) × (1 + 解码器)，乘法叠加

#### Scenario: 成功率
- **WHEN** 计算逆向成功率
- **THEN** 成功率 = 基础成功率 × (1 + 技能 + 设施 + 解码器)，不超过 100%

#### Scenario: 现金费用
- **WHEN** 计算现金费用
- **THEN** 基础费用 = 蓝图 baseCost × (1 + 技能加成)；总费用 = 基础费用 × 流程数

### Requirement: 解码器重做
8 个内置解码器，制造和逆向各自独立，以「材料效率」和「时间效率」中文名显示。

| 解码器 | 用途 | 材料效率 | 时间效率 | 额外效果 |
|--------|------|---------|---------|---------|
| 生产精算 | 制造 | -5% | +40% | - |
| 生产优化 | 制造 | -2% | -20% | - |
| 生产时效 | 制造 | +1% | -40% | - |
| 生产增量 | 制造 | +125% | +70% | +1 流程 |
| 逆向精算 | 逆向 | - | +40% | +30%成功率 |
| 逆向优化 | 逆向 | - | -10% | +10%成功率 |
| 逆向时效 | 逆向 | - | -40% | +5%成功率 |
| 逆向增量 | 逆向 | - | +50% | -50%成功率，+1流程 |

#### Scenario: 解码器选择
- **WHEN** 用户在制造面板选择解码器
- **THEN** 只显示用途为"制造"的解码器；逆向面板同理

### Requirement: 产品标签系统
产品通过树形分类节点自动继承父级标签。

#### Scenario: 标签继承
- **WHEN** 产品位于「舰船 > 护卫舰 > 加达里」节点下
- **THEN** 该产品自动拥有「舰船」「护卫舰」「加达里」标签

### Requirement: 折扣系统
三层折扣，优先级：手动覆写 > 材料清单覆写 > 全局规则。

#### Scenario: 全局折扣
- **WHEN** 用户设置分类折扣（如矿物 7 折）
- **THEN** 该分类下所有材料在「购买」计算时自动打折

#### Scenario: 材料清单覆写
- **WHEN** 用户在材料清单中为某行设置折扣
- **THEN** 该折扣覆写该物品的全局折扣

#### Scenario: 出售面板覆写
- **WHEN** 用户在出售面板设置折扣
- **THEN** 售价按折扣计算

### Requirement: 流程数修改
制造项目流程数不受蓝图上限限制，支持自定义输入。逆向工程增加并行流程数。

#### Scenario: 制造流程数
- **WHEN** 用户输入自定义流程数
- **THEN** 材料总数 = 单流程数量 × 流程数，计算所需槽位数

#### Scenario: 逆向并行流程
- **WHEN** 用户设置并行流程数
- **THEN** 期望成本 = (单次成本 / 成功率) × 并行流程数

### Requirement: 用户教程
主界面应展示简明教程文字，说明计算方式和工具使用方法。

### Requirement: 测试数据
内置秃鹫级截击型制造和逆向数据，以及护卫舰制造技术、加达里发明原理技能数据，用于与实机对比验证。

## MODIFIED Requirements

### Requirement: 引擎计算函数签名
**Original**: `calculateManufacturing(config, bp, decoder, getPrice)`
**New**: `calculateManufacturing(config, bp, decoder, getPrice, bonuses, productTags)`
bonuses 为分层加成对象，productTags 为产品标签列表。
