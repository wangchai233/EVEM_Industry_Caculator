# EVEM 工业计算器 v2 — 技能设施与公式重做 设计文档

> 日期: 2026-07-08 | A 期（基石）

## 概述

在现有计算器基础上，引入完整的游戏加成体系：玩家技能、工业设施、解码器重做、产品标签匹配、三层折扣系统。所有公式重构为分层加成管线。

## 分层加成管线

```
SkillResolver → FacilityResolver → DecoderResolver → BonusLayers
   (标签匹配)      (标签匹配)       (用户选择)          ↓
                                                   Engine
```

## 新公式

```
材料效率 = 1.5 + 技能加成 + 设施加成 + 解码器ME加成
时间消耗 = 基础时间 × (1 + 技能) × (1 + 设施) × (1 + 解码器)
成功率 = 基础成功率 × (1 + 技能 + 设施 + 解码器)，上限 100%
现金费用 = 基础费用 × (1 + 技能) × 流程数

折扣: 实际单价 = 原始单价 × (手动覆写 > 清单覆写 > 全局规则)
```

## 技能数据结构

```typescript
// 技能：每个技能有 3 阶段 × 5 等级的效果
interface SkillDef {
  matchTags: string[];  // 匹配产品标签
  base: { effects: SkillLevelEffect[5] };     // 基础 5 级
  advanced: { effects: SkillLevelEffect[5] }; // 进阶 5 级
  expert: { effects: SkillLevelEffect[5] };   // 专家 5 级
}

// 等级约束：进阶>0 → 基础≥4；专家>0 → 进阶≥5
// 预设: 000/540/550/553/554/555
```

## 产品标签

树形节点自动继承父级标签：

```
舰船 → [舰船, 常规舰船]
  └─ 护卫舰 → [舰船, 常规舰船, 护卫舰]
       └─ 加达里 → [舰船, 常规舰船, 护卫舰, 加达里]
```

## 折扣三层优先级

1. 全局分类折扣（矿物 7 折、行星菜 8 折等）
2. 材料清单单行覆写
3. 出售面板覆写

## 流程数

* 制造：自定义流程数，不受蓝图上限限制

* 逆向：并行流程数输入

* 计算槽位数 = ceil(流程数 / 单槽最大流程数)
