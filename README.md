# EVEM 工业计算器
**EVEM 工业计算器**（EVEM Industry Caculator）是为《星战前夜：无烬星河》手游（EVE 手游）玩家提供工业制造和逆向工程投入产出比计算的工具。

本工具可**完全离线**使用，内置游戏内各种工业产品的制造材料、费用、时间等数据，用户手动输入修正和价格，即可计算产品利润等信息。不使用内置配置的情况下，用户亦可**自定义**工业项目的几乎所有数据，生成并管理自己的配置。

界面适配电脑、手机和平板，但建议优先使用宽屏设备（宽度>767px）访问；竖屏下会精简部分信息。

资深工业玩家几乎都有自制的计算表格，本工具可提供适当的辅助。

## 主要功能
### 制造和逆向的计算
根据蓝图的基础数值，技能、设施和解码器等提供的修正，计算材料消耗、生产时间和成本；对于逆向工程，额外计算成功率和期望成本。

### 利润分析
结合市场或合同售价，计算制造或逆向利润。

### 多套价格方案和自定义产品
支持同时管理多套材料价格配置；支持自定义蓝图和逆向工程项目数据。

### 数据导入与导出
配置文件为 JSON 格式，可自由备份与恢复。

### localStorage 持久化
所有配置自动保存在浏览器中，可本地管理。

## 计算公式
```plain
材料效率 = 150% − 技能加成 − 设施加成 + 解码器加成，下限75%
时间消耗 = 基础时间 × (1+技能) × (1+设施) × (1+解码器)
成功率 = 基础成功率 × (1+技能+设施+解码器)，上限 100%
现金费用 = 基础费用 × (1+技能) × 流程数
```
> 通过游戏内数据反推得到。
>

技能和设施对材料效率的修正都是正面的。

在直觉上，“效率”是越高越好的，游戏内相关技能也使用“加材料效率”的表述。在工业计算中，材料效率直接与白板数量相乘，所以材料效率越低，则越省材料。

## 界面解释
初次打开将会自动展开使用帮助。本工具对游戏新手可能有较大使用难度，请仔细阅读教程。

在页眉设置全局价格方案，默认无价格。

页面由 3 个大板块组成：**技能与设施**、**工业**和**出售**。

### 技能与设施
此板块可精细调整工业相关的角色技能和军团设施，完全用于为工业板块提供前置全局修正。

适用于用户**不确定制造效率时模拟**，如果已经知晓，可以**跳过**此板块，在**工业**板块直接设置覆盖全局的修正。

技能滑块还原了游戏事实：高阶技能需要同名低阶技能达到一定等级才能训练，不是 bug。

> 目前不够完善。
>

### 工业
#### 选择模式
此板块是核心板块，可选择“**制造**”或“**逆向工程**”模式。加载的产品列表会显示在此处，两个模式的产品列表不互通。

#### 选定产品
直接搜索，或在树形菜单选中一个产品，将显示其信息。使用**标签**对所有产品分类。产品的标签决定了其在产品树中的位置，也决定其受哪些技能和设施的加成影响。

##### 产品树
产品树的每个节点都会继承比自己高一级的节点的标签，同时赋予比自己低级的所有节点自己的标签，因此所有产品自动获得从内到外路径上所有的标签。

对于自定义产品，只有选择合适的标签，才能使其获得用户想要的修正。

> 理论上，自定义产品创建后能自动追加进产品树，但似乎失败了。目前自定义产品的标签功能仍然不够好。
>

#### 全局效率修正
如果用户不使用技能和设施板块，可以在此处开关**覆盖全局**的材料效率、时间效率和成功率。

注意：材料效率和时间效率直接修改最终数值，而成功率在基础成功率上乘算。

#### 解码器
此功能尚不完善。

能正常提供修正，但暂时不能计算自身数量消耗。以后会把解码器消耗倍率嵌入项目配方数据中。

#### 基底材料
基底材料（Base）是我发明的概念。

+ 在制造项目的材料中，基底材料是此成品的蓝图；
+ 在逆向工程项目的材料中，基底材料是官方概念中的 “BaseItem”。

这个概念是材料在特定项目下的分类；只有在项目内，“基底”才有意义。某材料在制造项目 A 中可能是基底材料，在逆向项目 B 中又能是普通材料。使用这个概念区分出受和不受材料效率影响的材料，便于计算。

#### 材料清单
+ “忽略未填价格”若打开，则所有未录入的价格会被视为 0。默认关闭。
+ “材料数量取整”若打开，则“舰船”类型的材料数量会被 ceil()，其他类型材料数量会被四舍五入至整数。若关闭，则材料都以原始浮点数计算。此开关用于还原游戏机制，默认开启，**不建议关闭**。

> + 真的太坑了，1.01 条船也要算成 2 条船。
>

材料清单中可见各种类型材料的基准数量、修正数量和总数量。

+ 基准数量是**材料效率 100%**时的数量，是“白板数量”；
+ 修正数量是**当前材料效率**下的数量，即单流程的数量；
+ 总数量是**修正数量和项目流程数的乘积**。

> 竖屏下仅显示总数量。
>

可以单独或批量设置每件材料的价格和折扣。

> 尚不清楚全局折扣规则能否生效。
>

#### 总结面板
万事俱备。确认总结面板的各项数值，如果还想要计算收益，点击“发送到出售”按钮，然后转到**出售**板块。

### 出售
#### 自动发送项目成本
出售板块很简单，可以选择“市场出售”或“合同出售”模式，主要是税费不同。

如果项目总成本被成功发送过来，输入单件售价时应能显示“**利润分析**”总结面板。

技能板块不包含贸易学技能，因此可以在此处自定义市场销售税。提供一些预设。

#### 手动输入项目成本
如果出售板块没有接收到工业板块发送的成本，可以手动输入成本，适合单独使用此板块。

如果已经接收过，手动输入框会自动隐藏，刷新页面即可重现。

## 能力限制
本工具只能并行处理单个产品，对于旗舰等需要“套娃制造”的高级产品，计算效率提升不明显。未来可能考虑另做工作流式工业模拟器，以提高能力上限。
