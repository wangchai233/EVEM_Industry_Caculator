# 流程数修改
这是个游戏外的计算工具，所以制造项目的流程数上限不必被游戏内限制，可以在滑块旁边增加自定义的流程数量；因为逆向工程总是限制 1 流程每项目，所以增加“并行流程数”输入框。计算当前流程数需要占用的项目槽位数量并输出。

# 解码器修改
现对解码器进行补充说明，直接内置，然后删除原有的解码器。另外，你把制造和逆向的解码器混用了，实际上它们不通用。详见下文。

解码器的字段可以理解成：

| 字段 1 | 字段 2 | 含义 |
| --- | --- | :---: |
| 生产 | <br/> | 只能用于制造 |
| 逆向 | | 只能用于逆向 |
|  | 精算 | 你无需了解 |
| | 优化 | |
| | 时效 | |
| | 增量 | |


所有解码器如下：

+ 生产精算解码器
    - -5%ME +40%TE
+ 生产优化解码器
    - -2%ME -20%TE
+ 生产时效解码器
    - +1%ME -40%TE
+ 生产增量解码器
    - +1 流程 +125%ME +70%TE
+ 逆向精算解码器
    - +30%成功率 +40%TE
+ 逆向优化解码器
    - +10%成功率 -10%TE
+ 逆向时效解码器
    - +5%成功率 -40%TE
+ 逆向增量解码器
    - +1 流程 -50%成功率 +50%TE

必须在网页上显示为“材料效率”和“时间效率”；除非在公式内，否则不可使用英文缩写；必须对所有缩写作出解释。

# 产品列表和更多自定义功能
把产品列表改成默认折叠的，并增加多级列表功能（如舰船>战列舰>基础战列舰>乌鸦级）。实际使用时，列表可能会有数千个产品。

并且新增可以自定义的产品。逆向工程也要有自定义，别忘了成功率。

若选中自定义产品，产品的绝大部分信息都应能在网页上直接编辑。

自定义产品要能保存到当前列表，或者另存为新列表。为列表原有的产品和自定义新增的产品添加醒目区别标识。有不少高级物品需求不止 2 大种材料，产品的材料类型数量应能随意增减。

举例：用户想修改某列表中“乌鸦级”的配方，则选中此产品，将其另存为新的自定义产品“乌鸦级魔改型”，将基底材料改为 1 个“乌鸦级魔改型蓝图”，在“矿物需求”一栏里添加“莫尔石”为“10000”，新增“舰船需求”一栏，在其添加“乌鸦级”为“2”。
